Cách gọi API 
curl -X POST {{ api_base }}/external/vocabulary \
  -H "X-API-Key: voca_xxxx_yyyy" \
  -H "Content-Type: application/json" \
  -d '{
    "word": "leverage",
    "language": "en",
    "translation": "tận dụng",
    "meaning": "use something to maximum advantage",
    "context": {
      "sentence": "Financial institutions leverage derivatives...",
      "source_title": "Quant book",
      "location": "Chapter 3"
    },
    "source": "realtime_caption"
  }'

Chỉ word là bắt buộc. Từ đã có sẽ không bị tạo trùng: Voca chỉ bổ sung nghĩa, ngữ cảnh hoặc tag mới.

Gửi nhiều từ một lần (tối đa 100): POST {{ api_base }}/external/vocabulary/batch với {"items": ["hedge", {"word": "yield", "translation": "lợi suất"}]}. Đặc tả đầy đủ: OpenAPI, hướng dẫn trong thư mục docs/external-api của repo.
